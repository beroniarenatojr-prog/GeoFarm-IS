                         QUICK DECISION TREE
================================================================================

  Q: Haven't worked for days?
  └─> YES → startup.bat
      NO  → Continue below

  Q: Worked today/yesterday?
  └─> YES → npm run dev
      NO  → startup.bat

  Q: Changes not showing?
  └─> Solution: Ctrl + Shift + R

  Q: JavaScript errors in console?
  └─> Solution: npm run build

  Q: Vite manifest not found?
  └─> Solution: npm run build

  Q: Nothing works?
  └─> Solution: Nuclear reset (see above)

================================================================================

                         PREVENTION CHECKLIST
================================================================================

  Before Starting Work:
  ☐ XAMPP running (Apache + MySQL)
  ☐ Database exists (geofarm_is)
  ☐ Check last work date:
      • 2+ days ago? → Use startup.bat
      • Recent?      → Use npm run dev

  After Each Work Session:
  ☐ Stop servers (Ctrl+C)
  ☐ Commit changes (optional)
  ☐ Close terminals

  Weekly Maintenance:
  ☐ Run: npm install (update dependencies)
  ☐ Run: php artisan optimize:clear
  ☐ Check: storage/logs/laravel.log for issues

================================================================================

                         COMMAND REFERENCE
================================================================================

  Startup Commands:
  ┌─────────────────────────────────────────────────┐
  │ startup.bat          │ Full rebuild + start     │
  │ npm run fresh        │ Same as startup.bat      │
  │ npm run dev          │ Normal start             │
  │ npm run build        │ Rebuild assets only      │
  └─────────────────────────────────────────────────┘

  Troubleshooting Commands:
  ┌─────────────────────────────────────────────────┐
  │ php artisan optimize:clear │ Clear all caches   │
  │ npm run build              │ Rebuild assets     │
  │ composer dump-autoload     │ Refresh classes    │
  │ Ctrl + Shift + R           │ Hard refresh       │
  └─────────────────────────────────────────────────┘

                         SUCCESS INDICATORS
================================================================================

  ✅ Terminal shows:
     • "Laravel server started"
     • "Vite dev server running"
     • No error messages

  ✅ Browser shows:
     • Landing page loads
     • No console errors (F12)
     • Styles applied correctly

  ✅ After login:
     • Dashboard displays
     • Navigation works
     • Data loads properly
