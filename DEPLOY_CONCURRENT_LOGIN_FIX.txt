==========================================
DEPLOY: Prevent Concurrent Logins
==========================================

WHAT THIS DOES:
---------------
Prevents users from logging in on multiple
devices/browsers at the same time.

When User A logs in on Computer 1, then logs in
on Computer 2, Computer 1 is automatically logged
out.

==========================================
HOW IT WORKS
==========================================

LOGIN:
------
When user logs in, their session ID is saved
in the database (users.active_session_id)

EVERY REQUEST:
--------------
Middleware checks if current session ID matches
the one in database

IF DIFFERENT:
-------------
User is logged out (their session was replaced
by a newer login from another device)

LOGOUT:
-------
Session ID is cleared from database, so user
can log in again from any device


==========================================
BENEFITS
==========================================

✅ Prevents account sharing
✅ One user per account at a time
✅ Security improvement
✅ Detects unauthorized access
✅ Works automatically (no user action needed)


==========================================
USER IMPACT
==========================================

BEFORE:
- Users could log in on multiple devices
- No way to enforce single session

AFTER:
- Only one active session per user
- Old session logged out automatically
- User sees clear message explaining why


==========================================
CONFIGURATION
==========================================

SESSION_LIFETIME=120
