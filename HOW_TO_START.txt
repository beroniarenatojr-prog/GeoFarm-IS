SCENARIO 1: Opening Project After DAYS (Most Common Issue!)
────────────────────────────────────────────────────────────────────────────
   Problem: JavaScript errors, blank screen, "Cannot read properties..."
   
   Solution: Double-click or run in terminal
   
   ╔═══════════════════╗
   ║   startup.bat     ║  ← Just run this!
   ╚═══════════════════╝
   
   What it does:
   1. Clears Laravel caches
   2. Rebuilds JavaScript assets (fixes the stale build!)
   3. Starts servers automatically
   
   Then visit: http://127.0.0.1:8000

────────────────────────────────────────────────────────────────────────────

SCENARIO 2: Daily Development (Worked on project today/yesterday)
────────────────────────────────────────────────────────────────────────────
   Just run:
   
   ╔═══════════════════╗
   ║  npm run dev      ║
   ╚═══════════════════╝
   
   Then visit: http://127.0.0.1:8000

────────────────────────────────────────────────────────────────────────────

QUICK FIXES
────────────────────────────────────────────────────────────────────────────
   Changes not showing?
   └─> Press: Ctrl + Shift + R (hard refresh browser)
   
   Still broken?
   └─> Run: npm run build
       Then: npm run dev
       Then: Ctrl + Shift + R

REMEMBER
────────────────────────────────────────────────────────────────────────────
   ❌ DON'T: Just run "npm run dev" after days of inactivity
   ✅ DO:    Run "startup.bat" to rebuild assets first!
   
   Why? The JavaScript build gets stale and causes errors!

CHECKLIST BEFORE STARTING
────────────────────────────────────────────────────────────────────────────
   [ ] XAMPP is running (Apache & MySQL)
   [ ] Database exists: geofarm_is
   [ ] Haven't worked on project for days? → startup.bat
   [ ] Worked on project recently? → npm run dev
