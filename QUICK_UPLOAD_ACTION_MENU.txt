QUICK UPLOAD: 3-DOT ACTION MENU
==========================================

WHAT THIS DOES:
---------------
Replaces the 4 inline action buttons with a single
3-dot menu button that opens a dropdown.

BEFORE:  [👁️] [✏️] [🗑️] [🔒]
AFTER:   [⋮] → Click to see all actions

==========================================
SSH COMMANDS
==========================================

ssh your-server
cd ~/public_html
php artisan cache:clear
php artisan view:clear


==========================================
TEST IT
==========================================

1. Go to: https://geo-farm.pitonmain.com/admin/assistance

2. Look at the "Actions" column

3. You should see a 3-dot button (⋮)

4. Click it → Dropdown menu appears with:
   • View
   • Edit
   • Delete  
   • Lock/Unlock

5. Click outside the menu → It closes

6. Try each action → Should work like before
