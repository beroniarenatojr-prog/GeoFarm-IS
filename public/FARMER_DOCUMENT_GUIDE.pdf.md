# 📄 Gabay sa Pag-compile ng mga Dokumento para sa Farmer Registration
## Guide to Compiling Documents for Farmer Registration

---

## ⚠️ MAHALAGANG PAALALA / IMPORTANT REMINDER

**Lahat ng inyong dokumento ay dapat ISANG PDF FILE lamang!**
**All your documents must be compiled into ONE PDF FILE only!**

---

## 📋 Mga Kinakailangang Dokumento / Required Documents

Kailangan ninyong i-compile ang **APAT (4) na dokumento** sa isang PDF file:

You need to compile **FOUR (4) documents** into one PDF file:

### 1️⃣ RSBSA Georeferencing Stub
- Ang resibo mula sa RSBSA georeferencing
- Receipt from RSBSA georeferencing

### 2️⃣ RSBSA Form
- Ang kumpleto na RSBSA form ninyo
- Your complete RSBSA form

### 3️⃣ Barangay Certification
- Sertipikasyon mula sa inyong barangay
- Certification from your barangay

### 4️⃣ Valid ID
- Dalawang (2) valid government-issued ID
- Two (2) valid government-issued IDs

**Halimbawa ng Valid ID / Examples of Valid IDs:**
- Driver's License
- Passport
- PhilSys ID / National ID
- SSS ID
- GSIS ID
- Postal ID
- Voter's ID

## 🎯 Paano I-compile ang mga Dokumento / How to Compile Documents

### Hakbang 1: I-scan o Kunan ng Litrato / Step 1: Scan or Take Photos

**✅ DAPAT GAWIN / DO's:**
- Gumamit ng scanner kung meron (mas malinaw)
- Use a scanner if available (clearer)
- Kung wala, kunan ng litrato gamit ang camera/cellphone
- If not available, take photos using camera/cellphone
- Siguraduhing malinaw at mabasa ang lahat ng teksto
- Make sure all text is clear and readable
- Ituwid ang papel bago kunan
- Straighten the paper before taking photo
- May sapat na liwanag (natural light ay mas maganda)
- Use sufficient lighting (natural light is better)
- Walang mga anino sa dokumento
- No shadows on the document

**❌ HUWAG GAWIN / DON'Ts:**
- Malabong litrato / Blurry photos
- Kulang ang dokumento sa frame / Document is cut off in frame
- May mga daliri sa harap ng dokumento / Fingers covering the document
- Sobrang dilim o sobrang liwanag / Too dark or too bright
- Baluktot o liko ang dokumento / Document is folded or crooked

### Hakbang 2: I-convert sa PDF / Step 2: Convert to PDF

**Opsyon A: Gumamit ng Online Tool / Option A: Use Online Tool**

1. Pumunta sa kahit ano sa mga website na ito:
   Visit any of these websites:
   - www.ilovepdf.com
   - www.smallpdf.com
   - www.pdf2go.com

2. Piliin ang "JPG to PDF" o "Merge PDF"
   Choose "JPG to PDF" or "Merge PDF"

3. I-upload ang lahat ng inyong mga imahe
   Upload all your images

4. Ayusin ang pagkakasunod-sunod:
   Arrange the order:
   - Una: RSBSA Georeferencing Stub
   - Pangalawa: RSBSA Form
   - Pangatlo: Barangay Certification
   - Pang-apat: Valid IDs (dalawa)

5. I-click ang "Convert" o "Merge"

6. I-download ang PDF file

**Opsyon B: Gumamit ng Mobile App / Option B: Use Mobile App**

Mag-install ng app sa inyong cellphone:
Install an app on your cellphone:
- **CamScanner** (Android/iOS)
- **Adobe Scan** (Android/iOS)
- **Microsoft Lens** (Android/iOS)
- **Google Drive** (may built-in scan)

Sundin ang instructions ng app:
Follow the app's instructions:
1. I-scan ang bawat dokumento
2. I-adjust kung kailangan
3. I-save lahat sa isang PDF

**Opsyon C: Sa Computer / Option C: On Computer**

**Windows:**
1. I-open ang lahat ng imahe sa Photos app
2. I-print (Ctrl+P)
3. Piliin "Microsoft Print to PDF" bilang printer
4. I-save ang file

**Microsoft Word:**
1. I-open ang Word
2. I-insert ang lahat ng imahe (Insert > Pictures)
3. I-save as PDF (File > Save As > PDF)

## 📏 Mga Pamantayan ng Kalidad / Quality Standards

### ✅ Dapat / Must Have:
- **Malinaw ang teksto** / Text is clear
  - Mabasa ang lahat ng nakasulat
  - All text is readable

- **Kumpleto ang dokumento** / Document is complete
  - Walang naputol na parte
  - No parts are cut off

- **Tama ang oryentasyon** / Correct orientation
  - Tuwid ang dokumento, hindi nakabaluktot
  - Document is straight, not tilted

- **Angkop ang laki ng file** / Appropriate file size
  - Hindi mas maliit sa 100 KB (masyadong maliit)
  - Not smaller than 100 KB (too small)
  - Hindi mas malaki sa 10 MB (masyadong malaki)
  - Not larger than 10 MB (too large)
  - **Ideal: 500 KB - 5 MB**

- **PDF format lamang** / PDF format only
  - Hindi ZIP, RAR, o iba pang format
  - Not ZIP, RAR, or other formats

### ❌ Hindi Tatanggapin / Will NOT be Accepted:
- Malabong imahe / Blurry images
- Hindi kompleto ang dokumento / Incomplete documents
- Maling dokumento / Wrong documents
- Hindi PDF ang format / Not in PDF format
- Masyadong maliit o malaki ang file / File too small or too large

## ⚠️ Mga Karaniwang Mali / Common Mistakes

### 1. Hiwalay-hiwalay ang mga file / Separate files
**Mali / Wrong:** 4 PDF files
**Tama / Correct:** 1 PDF file na may 4 documents

### 2. Hindi PDF ang format / Not PDF format
**Mali / Wrong:** .jpg, .png, .zip, .rar
**Tama / Correct:** .pdf

### 3. Malabo ang imahe / Blurry image
**Solusyon / Solution:** I-scan ulit gamit ang mas mataas na resolution
Re-scan using higher resolution

### 4. Kulang ang dokumento / Missing documents
**Solusyon / Solution:** Siguraduhing kompleto ang apat (4)
Make sure all four (4) are complete

### 5. Masyadong malaki ang file / File too large
**Solusyon / Solution:** I-compress ang PDF
Compress the PDF
