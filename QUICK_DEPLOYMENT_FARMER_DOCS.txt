==========================================
QUICK DEPLOY: Farmer Document Instructions
==========================================

WHAT THIS DOES:
---------------
Adds clear instructions for farmers to compile
their 4 required documents into ONE PDF file.

Reduces confusion and speeds up verification!


==========================================
FILES TO UPLOAD
==========================================

1. UPDATED FORM
   resources/js/Pages/Admin/Farmers/FormRSBSA.jsx
   → ~/public_html/resources/js/Pages/Admin/Farmers/

2. GUIDE DOCUMENTS
   public/FARMER_DOCUMENT_GUIDE.pdf.md
   public/DOCUMENT_REQUIREMENTS.txt
   → ~/public_html/public/

3. BUILD ASSETS
   Extract build.zip to:
   → ~/public_html/public/build/


==========================================
COMMANDS TO RUN
==========================================

ssh your-server
cd ~/public_html
php artisan cache:clear
php artisan view:clear


==========================================
WHAT FARMERS WILL SEE
==========================================

On the registration form, a BLUE BOX appears with:

📄 Required: Compile ALL 4 documents into ONE PDF

1. RSBSA Georeferencing Stub
2. RSBSA Form (completed)  
3. Barangay Certification
4. Valid ID (2 government-issued IDs)

⚠️ Upload CLEAR scanned or photographed images

✅ PDF format only • Max 10MB • Clear images required


==========================================
REQUIRED DOCUMENTS (All in ONE PDF)
==========================================

1. RSBSA Georeferencing Stub
2. RSBSA Form
3. Barangay Certification
4. Valid ID (2 pieces)

Examples of Valid ID:
- Driver's License
- Passport
- PhilSys ID / National ID
- SSS ID, GSIS ID
- Postal ID, Voter's ID
